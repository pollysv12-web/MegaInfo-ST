# MegaInfo 0.3.1 — инфоблоки для SillyTavern

Состояние персонажей, отношения, сюжет и значимые вещи в одном расширении.
Модель сообщает события, а код считает итоговые числа: спад потребностей по
игровому времени, траты, шкалы отношений и заживление. Данные сохраняются внутри
сообщений; старые служебные блоки не попадают в историю для модели.

## Установка и обновление

В SillyTavern откройте **Расширения → Install extension** и вставьте:

```text
https://github.com/pollysv12-web/MegaInfo-ST
```

В поле **Branch** укажите **`claude/tender-mayer-gfobei`** — текущую рабочую ветку.
Точный выпуск отмечается тегом **`v0.3.1`**. Ветка `main` пока содержит ранний выпуск;
пробное оформление `test-UI` вошло в 0.3.1.

Для обновления выберите MegaInfo в **Manage extensions** и перезагрузите страницу.
Если расширение установлено из другой ветки, переключите её на рабочую ветку.
Сохранённые параметры и данные чатов не сбрасываются.

Настройки находятся в **Расширения → MegaInfo · инфоблоки**. Быстрые переключатели
и настройки только текущего чата: **волшебная палочка → MegaInfo**.

Перед первым запуском выключите дублирующие инфоблоки скриптов и пресетов.
Регулярки, удаляющие `<megainfo>` или прежние служебные теги из исходного ответа,
могут удалить данные раньше расширения.

## Что изменилось в 0.3.1

- Оформление `test-UI` объединено с рабочей версией: розовые и красные акценты,
  компактные вкладки, название **Slow burn**.
- **Возбуждение** — эмоциональная энергия: азарт, радость, предвкушение.
  **Страсть** — сексуальное возбуждение. Прежние сексуальные значения сохраняются
  как страсть; обновление не превращает их в радость или азарт.
- Нажатие на число раскрывает **причины плюса и минуса**: игровое время, событие
  или ручная правка. Пояснение можно свернуть; при наведении доступна подсказка.
  Если модель не уточнила причину события, расширение так и пишет.
  В старых сообщениях причины могли не сохраняться: обновление не выдумывает их задним числом.
- Карандашики в **Пульсе** позволяют исправить показатели, настроение, одежду,
  мысли, деньги и профиль без редактирования JSON.
- Шесть игровых наборов, выбор отслеживаемых персонажей, порядок вкладок,
  раскрываемые сведения, размер текста и контрастность.
- **Нити сюжета** для обещаний и открытых событий; **Кармашек** для значимых вещей.

История всех выпусков: [CHANGELOG.md](CHANGELOG.md).

## Блоки

| Блок | Что показывает |
|---|---|
| **Пульс** | Дата, время, погода, место; сытость, гигиена, бодрость, возбуждение и страсть; настроение, одежда, мысли, деньги и профиль. Показатели и сведения редактируются карандашиком. |
| **Связи** | Симпатия, характер отношений и мысли. Изменение за один ответ ограничено настройкой. |
| **Slow burn** | Десять стадий сближения, скорость развития и сила влияния стадии на поведение. |
| **Сюжет** | Прогресс, напряжение, расписание, слухи и нити: обещания, загадки, назначенные встречи. Возможные завершения раскрываются нажатием; пункт можно убрать вручную. |
| **Места** | Описание нового места и сохранённая атмосфера; одно и то же место не нужно описывать каждый ход. |
| **Следы** | Травмы и следы с заживлением по игровому времени. Новые татуировки и пирсинг — по настройке. След можно убрать вручную. |
| **Заметки** | Личная запись до или после ответа, раздел об игроке и записи окружения. |
| **На связи** | Переписки и уведомления внутри текста рядом с использованием телефона. Для мира без телефонов блок выключается в настройках чата. |
| **Детали** | Письмо, чек, пост или вывеска внутри ответа. HTML очищается и изолируется от интерфейса таверны. |
| **Кармашек** | Значимые вещи бота, игрока и выбранных NPC: ключ, подарок, письмо, улика. Добавление, правка и удаление. |

Карандашик меняет значение **в текущем ответе и активном свайпе**. Новые ответы
считаются от актуального последнего состояния. Уже существующие последующие
ответы не пересчитываются задним числом.

## Настройка под игру

В панели оформления есть разделы **Вид / Персонажи / Наборы**. В **Наборах**
прочитайте описание и нажмите применение выбранного варианта:

| Набор | Для чего |
|---|---|
| **Повседневность** | Спокойные сцены, потребности, близкие люди, места, заметки и важные вещи. |
| **Медленный роман** | Медленный Slow burn, небольшие шаги симпатии и подробные заметки. |
| **Интриги** | Связи, слухи, обещания, сюжетные нити и значимые предметы. |
| **Только самое нужное** | Облегчённый Пульс с временем и местом, без дополнительных блоков. |
| **Саспенс** | Напряжение, следы, места, сюжетные зацепки и улики при себе. |
| **Быстрая страсть** | Быстрее развивающиеся отношения и более свободный темп Slow burn. |

Наборы меняют игровые параметры модулей, сохраняют подключение к модели,
выбранную тему и данные чатов. После применения всё можно настроить вручную.

В **Виде** задаются порядок вкладок, сведения Пульса (сразу, по нажатию или скрыто),
размер текста, контрастность, тема и шрифт. Остальные параметры блоков остаются
в собственных раскрывающихся разделах.

В **Персонажах** можно подробно вести бота и игрока, закрепить важного NPC,
а остальных учитывать кратко. Для конкретного персонажа выбираются нужные
сведения: состояние, настроение и возбуждение, одежда, мысли, деньги, профиль,
отношения и кармашек. Выбор влияет на запрос данных и их показ; прежние сохранённые
сведения от отключения не удаляются.

Автоматический **Кармашек** учитывает **до пяти значимых вещей на человека**
по умолчанию. Он не обязан заполнять все места и не составляет опись всей одежды.
Автоматику можно выключить и вести список вручную; лимит меняется в настройках блока.

**Нити сюжета** хранят открытые обещания, встречи и вопросы. По умолчанию — до
шести активных нитей. Возможные развязки служат подсказками и не завершают события
без действий в игре. Закрытую или ненужную нить можно удалить.

## Как приходят данные

- **Авто:** блок в ответе; при пропуске или ошибке — отдельный запрос.
- **Только в ответе:** без дополнительных запросов за пропущенным блоком.
- **Только отдельным запросом:** данные запрашиваются после основного ответа.

Отдельный запрос бывает лёгким (последние сообщения) и полным (больше контекста,
описания персонажа и персоны); можно выбрать другой профиль подключения.
Частота обновления задаётся по блокам. Заметки обычно приходят вместе с ответом.

Модель отправляет `<megainfo>{…}</megainfo>`. Для телефона и карточек в нужном
абзаце используются `[[mi:phone]]` и `[[mi:card]]`, HTML передаётся в `<megainfo_html>`.
Всё служебное убирается из истории для модели. Панель, её свёрнутость и раскрытые
пояснения сохраняются вместе с сообщением и активным свайпом.

## Диагностика

В **Логах и диагностике** доступны **Что видит модель**, **Скопировать диагностику**
и экспорт JSON/Markdown текущего чата. Экспорт содержит личные данные игры.
В режиме «Только в ответе» пропущенный моделью блок не вызывает дополнительного
запроса; для восстановления выберите «Авто».

## Проверки для разработки

```sh
npm ci --ignore-scripts
npm test
npm run test:browser
npm run test:browser:v31
```

Нужен Chromium; путь задаётся через `MEGAINFO_CHROMIUM_PATH`.
Стенд `test/browser/` проверяет интеграцию на макете. Настоящий SillyTavern
проверяется отдельно в тестовом чате; запуск стенда не означает проверку
конкретного сервера пользователя или провайдера модели.
