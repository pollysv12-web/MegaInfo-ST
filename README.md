# MegaInfo 0.3.0-ui.1 — оформление test-UI

Инфоблоки для SillyTavern: состояние персонажей, связи, развитие романа, сюжет и места,
следы на теле, личные заметки, переписки и предметы сцены.

**Главное отличие от скриптов и тоглов:** числа считает код, а не модель.
Модель только сообщает, что произошло («поел», «потратил 450 ₽», «симпатия +2», «появился синяк»),
а расширение само пересчитывает статы, баланс, шкалы и заживление. Поэтому ничего не скачет,
деньги сходятся, а синяк не исчезает за одно сообщение.

**Контекст остаётся чистым.** Модель присылает короткий блок `<megainfo>{…}</megainfo>`, расширение
вырезает его из текста, сохраняет внутри сообщения и рисует из него панель. В историю, которую видит модель,
старые блоки не попадают — регулярки для этого не нужны.

## Ветка оформления

`test-UI` — отдельный вариант интерфейса на основе 0.3.0: короткие названия и обновлённое оформление.
Настройки, история чатов, числовые расчёты и протокол модели сохраняют прежний формат.
Переименованы подписи на экране; технические ключи модулей остаются прежними.

| Было | Здесь |
|---|---|
| Sims | Пульс |
| Отношения | Связи |
| Слоуберн | Сближение |
| Мир и сюжет | Сюжет |
| Локация | Места |
| Следы на теле | Следы |
| Дневник | Заметки |
| Телефон | На связи |
| HTML-карточки | Детали |

«Пульс» показывает потребности, настроение и одежду; «Заметки» — развёрнутую личную запись после сцены.
Короткие мысли в состоянии персонажа остаются отдельным полем.

## Установка

В SillyTavern: **Расширения (значок кубиков) → Install extension** → вставить ссылку:

```
https://github.com/pollysv12-web/MegaInfo-ST
```

Для этого варианта оформления укажите **`test-UI`** в поле *Branch*.
Основная версия 0.3.0 находится в ветке `claude/tender-mayer-gfobei`.
Настройки появятся в меню расширений
в разделе **MegaInfo · инфоблоки**. Быстро включать и выключать блоки удобно через **волшебную палочку
→ MegaInfo** — там же настройки только для текущего чата (например, «в этом мире нет телефонов»).

**Обновление:** Расширения → Manage extensions → кнопка обновления у MegaInfo.

## Перед первым запуском — выключите дубли

Иначе модель получит две противоречащие инструкции, и блоки будут ломаться:

1. **Скрипты Кисы** (sims, diary, phone, plot compass) — выключите в Tavern Helper.
2. **Тоглы пресета** с инфоблоками, телефоном и HTML-карточками — выключите в пресете.
3. **Регулярки**, которые удаляют теги из ответа (`<sims>`, «HTML Vanquisher» и т. п.) без галочек
   «только промпт» / «только форматирование». Они срабатывают раньше расширения и могут съесть его блок.

## Блоки

| Блок | Что делает |
|---|---|
| **Пульс** | Дата, день недели, время, погода, место. Сытость, гигиена, бодрость и сексуальное возбуждение меняются по времени и событиям. Деньги по каждой трате, одежда с учётом частичных изменений, настроение, тайные мысли. Во вкладке «Общая информация»: д/р, знак, MBTI с описанием по нажатию или наведению. Есть **облегчённый вариант**: только дата, время, погода, место. |
| **Связи** | Шкала симпатии к вам от −100 до 100 у персонажа и NPC, название отношений, тайные мысли. Главный персонаж показывается первым. Шаг за один ответ ограничен (по умолчанию ±5), поэтому без скачков. |
| **Сближение** | 10 стадий: Незнакомцы → … → Признание → Вместе. Настраиваются скорость и сила влияния стадии на диалоги, доверие, инициативу и близость. Ограничение: не больше одной новой стадии за игровой день. |
| **Сюжет** | Напряжение (+3% за спокойную сцену, +1% за активную, на 100% — крупный поворот и сброс), сюжет с прогрессом, расписание персонажей, 3–4 слуха, которые NPC упоминают в разговорах. |
| **Места** | Подробное описание места: как выглядит, что есть, атмосфера. Пишется **только при попадании в новое место** и хранится в чате. |
| **Следы** | Синяки, засосы, укусы, порезы, пулевые и ножевые раны, ожоги, обморожения, переломы и окрашивание кожи. Заживление зависит от типа, тяжести и выбранной скорости. Новые татуировки и пирсинг — по настройке; исходные особенности персонажа не добавляются. Любой след можно убрать вручную. Окружающие видят только то, что не скрыто одеждой, и реагируют по характеру. |
| **Заметки** | Отдельная запись **в начале или в конце ответа**, раздел **«О нём / о ней / о них»**, заметки окружения, сплетни. Длина, глубина и частота настраиваются. По умолчанию создаётся вместе с ответом. При отдельном запросе сначала видно ожидание, затем готовую запись. |
| **На связи** | Переписки, посты, уведомления **внутри текста ответа**, рядом с использованием телефона. Стиль один, выбранный вами (iPhone, Telegram, стекло, тема таверны). Для фэнтези-чата телефоны выключаются в быстром меню. |
| **Детали** | Пост, письмо, чек, газета или вывеска появляются **в тексте ответа** рядом с событием. Стиль подстраивается под сеттинг. Карточка изолирована и не ломает тему таверны. |

Панель — вкладками (компактно) или блоками друг под другом. Темы: **как в таверне** (берёт цвета вашей темы),
стекло, чернила, бумага, мята, минимал, свои цвета, плюс поле для своего CSS.
Свёрнутость панелей сохраняется после перезагрузки чата. «На связи», «Детали» и «Заметки» показываются отдельно от основной панели.

Кнопки на панели: ⟳ — пересчитать блок отдельным запросом, ✎ — поправить значения руками,
📖 — добавить личную заметку.

## Потребности и дни рождения

При гигиене ниже 25%, сильном голоде или усталости модель получает подсказку о заметных признаках.
Реакция зависит от характера и ситуации: без обязательных замечаний и преувеличений.
При нулевой сытости или бодрости возможны слабость и обморок с учётом сцены.

Сексуальное возбуждение больше не растёт само. По умолчанию оно снижается со временем; скорость можно
изменить или выставить 0, чтобы оставить только изменения от событий. Азарт и эмоциональная радость
учитываются отдельно и не вызывают сексуальное поведение. Подсказки о сексуальном возбуждении
появляются только при высоком значении и учитывают текущую стадию отношений.

Опция **«Учитывать дни рождения в игре»** назначает недостающую дату один раз и сохраняет её.
Заданные даты остаются в приоритете. Когда день рождения наступает по игровому календарю,
близкие могут вспомнить о нём естественно; заранее напоминать не будут.

**«Разрешить мысли {{user}}»** по умолчанию выключено. Включайте, если разрешаете модели писать
внутренние мысли вашей персоны в состоянии.

Для заметок без ожидания второго запроса выберите **«Вместе с ответом бота»**.
При обновлении прежний выбор отдельного запроса сохраняется.

## Как получать блоки (режимы)

- **Авто** (по умолчанию) — блок приходит в ответе бота. Если модель забыла его, сломала или ответ оборвался,
  расширение само добирает блок отдельным запросом.
- **Только в ответе** — дешевле всего, без отдельных запросов.
- **Только отдельным запросом** — ответ бота не тратит длину на блок, надёжнее всего.

Отдельный запрос бывает **лёгким** (последние N сообщений + инструкция, можно на дешёвой модели через
профиль подключения) и **полным** (последние 60 сообщений, описание персонажа и персоны: дороже, но точнее).

У каждого блока есть «каждые N ответов» — между обновлениями значения сохраняются, а токены не тратятся.

## Логи

- **Скачать логи инфоблоков** — всё по текущему чату в JSON (можно хранить как резервную копию).
- **Логи текстом** — то же читаемым Markdown.
- **Скачать заметки этого чата** — все личные записи одним файлом.

## Если что-то не работает

1. Настройки → MegaInfo → **Скопировать диагностику** и пришлите текст разработчику. Там видно, что
   расширение попросило у модели, пришёл ли блок, чем закончился отдельный запрос.
2. Кнопка **«Что видит модель»** показывает точный текст инструкции.
3. В диагностике строчка «в ответе нет блока» при режиме «Только в ответе» означает, что модель проигнорировала
   инструкцию. Тогда помогут режим «Авто» или проверка регулярок (см. выше).

## Для разработчика

```
npm test
```

Браузерные проверки на макете SillyTavern:

```
npm install --ignore-scripts
npm run test:browser
```

Для браузерных проверок нужен Chromium, доступный Playwright.

Логика без интерфейса лежит в `src/core/` и тестируется в node. Работа с таверной — `src/tracker.js`,
отрисовка — `src/render.js`.
