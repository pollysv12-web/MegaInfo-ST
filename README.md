# MegaInfo — инфоблоки для SillyTavern

Расширение рисует красивые инфоблоки в ответах бота и при этом **не засоряет контекст**:
модель присылает короткий блок с данными, расширение вырезает его из текста, сохраняет внутри
сообщения и рисует из него карточку. Старые блоки в историю, которая уходит модели, не попадают.

## Что уже есть (v0.1)

**Sims**: дата, время, погода, локация; статы {{char}}, {{user}} и NPC; настроение, одежда,
мысли, деньги, общая информация (д/р, знак, MBTI).

- Числа считает код, а не модель: спад статов по времени, баланс по тратам. Статы не скачут, деньги сходятся.
- Три режима: в ответе / отдельным запросом / авто (в ответе, а если модель забыла блок, дозапрос).
- Для отдельного запроса можно выбрать другой, более дешёвый профиль подключения.
- Кнопки на блоке: ⟳ перегенерировать только блок, ✎ поправить значения руками.
- Слайдеры или компактный вид, 3 стиля, цвета берутся из вашей темы.
- В настройках показан расход токенов.

## Установка

В SillyTavern: **Расширения (значок кубиков) → Install extension** → вставить ссылку:

```
https://github.com/pollysv12-web/MegaInfo-ST
```

Настройки появятся в том же меню в разделе **MegaInfo · инфоблоки**.

> Если у вас стоят скрипты Кисы (sims/diary), выключите их, иначе блоки будут дублироваться.

## Планы

Дневник и слухи → слоуберн и отношения, расписание → локации и переписки → травмы и метки → тогл карточек.
